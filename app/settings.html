الرسائل النصية

قواعد التذكير

حدد لكل سجل موعد التذكير والقنوات والمستلمين.

ربط المنصات (API)

مفتاح لكل منصة. يظهر مرة واحدة عند إنشائه.

طريقة الاستخدام 
# ping
curl -H "Authorization: Bearer tt_live_..." https://appmails.net/api/v1/ping

# import JSON
curl -X POST -H "Authorization: Bearer tt_live_..." -H "Content-Type: application/json" \
  -d '{"tracker":"القضايا","rows":[{"title":"جلسة","due":"2026-10-01","category":"قضية","amount":500}]}' \
  https://appmails.net/api/v1/import

# import CSV / Excel file
curl -X POST -H "Authorization: Bearer tt_live_..." -F "file=@items.xlsx" -F "tracker=القضايا" \
  https://appmails.net/api/v1/import

# export
curl -H "Authorization: Bearer tt_live_..." "https://appmails.net/api/v1/items?tracker=&format=csv"
